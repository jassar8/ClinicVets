# RunApp

This folder holds a **ready-to-run copy** of ClinicVets after each successful **build** or **publish**.

- Double-click **`ClinicVets.exe`** here (keep everything in this folder together).
- Contents are **generated** — do not add source code here.
- After a **Release** self-contained publish, this folder matches a portable app layout.

If the folder is empty, build the desktop project or run `.\publish-win-x64.ps1` from the repository root.
